# Contributing to geowarden

Thanks for your interest! Bug reports, ideas and pull requests are welcome.

## Reporting bugs and ideas

Open an [issue](https://github.com/tommx0/geowarden/issues/new/choose). For bugs, the template asks for the
version, the log and the loaded rules, which usually saves a round of questions.
Security problems go through [private reporting](SECURITY.md) instead.

## Pull requests

- Keep changes small and focused, one topic per pull request.
- Match the existing style: Bash for the rule loader (`src/geowarden-apply`), plain Python 3
  without extra packages for the menu (`src/geowarden`).
- Test on a Debian or Ubuntu machine or container: build with `./build.sh`, install the package,
  turn blocking on and check `sudo nft list chain inet geowarden prerouting`.
- Never lock anyone out: changes must keep established connections, unfiltered interfaces
  and the open ports working, and a failed update must leave the current rules in place.
- Add a line to `debian/changelog` if the change is visible to users.

## Project layout

| Path | What it is |
|---|---|
| `src/geowarden` | Menu (whiptail), statistics, world map |
| `src/geowarden-apply` | Downloads the geo data and loads the nftables rules |
| `src/geowarden.conf` | Default configuration |
| `src/worldmap.txt` | World map grid, generated by `tools/make-worldmap.py` |
| `debian/` | Package metadata and maintainer scripts |
| `build.sh` | Builds the `.deb` package |
