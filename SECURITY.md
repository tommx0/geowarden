# Security policy

geowarden changes the firewall of your server, so security problems matter a lot.

## Reporting a vulnerability

Please **do not open a public issue**. Report the problem privately through
[GitHub's private vulnerability reporting](https://github.com/tommx0/geowarden/security/advisories/new)
(tab *Security* → *Report a vulnerability*).

Please describe what an attacker could do, which version you used and how to reproduce it.
You will get an answer as soon as possible.

## Supported versions

Only the latest release receives fixes.
